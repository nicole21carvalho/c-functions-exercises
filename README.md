# 🔧 Lista 4: Funções em C

Exercícios de **funções em linguagem C**: parâmetros, retorno, recursão e validação de entrada.

## 📚 Exercícios

| # | O que faz | Conceito |
|---|---|---|
| 1 | Mostra o menor entre dois números | operador ternário |
| 2 | Calcula a distância euclidiana entre dois pontos | `math.h` (`sqrt`, `pow`) |
| 3 | Calcula a potência de um número | recursão |
| 4 | Mostra o valor absoluto de 5 números | função dentro de laço |
| 5 | Soma os divisores de um número positivo | validação de entrada |
| 6 | Calcula a média aritmética, ponderada ou harmônica de 3 notas | escolha por parâmetro |
| 7 | Diz se um número é par ou ímpar | retorno verdadeiro/falso |
| 8 | Diz se um número é positivo, negativo ou zero | retorno com código |

gcc "Lista 4/ativ 1 lista 4.c" -o ativ1 -lm
